# Zero Hour Archipelago 0.8.0 - Steam preview

Supported: stock English Steam Zero Hour on Windows, campaigns and Generals
Challenges. This is a preview, not an online multiplayer integration.

## Assets

- **ZeroHour-Archipelago-0.8.0-Steam.zip**: client, world, options creator/example,
  optional mission-start saves, setup and read-only diagnostics.
- **generals_zh.apworld**: world for Archipelago 0.6.7.
- **ZeroHour-Archipelago-0.8.0-Source.zip**: clean source/build files.
- **SHA256SUMS.txt**: checksums.

Includes configurable mission checks/goals, unlocks, twelve builders, four
permanent abilities, progressive points, weighted filler/traps, DeathLink,
tracker/notifications, Light/Dark launcher and remembered fields.

Public 0.8.0 follows internal 0.21.1. World 0.20.0, protocol 17 and IDs stay unchanged.
Existing compatible rooms/progress work. Close the old client and restart the game
when updating. New seed options/items require the corresponding generated seed.

EA App, Origin, First Decade, GeneralsOnline and GenTool/GenPatcher combinations
are unvalidated. The compatibility report checks on-disk layout and SHA-256,
not running modifications. Permanent Emergency Repair Level 3 uses a four-minute
cooldown; live healing confirmation remains outstanding.

Instructions/issues: https://github.com/ItsMrNew/ZeroHour-Archipelago

Validation: 1,389 automated tests passed, options-creator checks passed, real
Archipelago generation/handshake checks passed, and 327 native-layout anchors
verified against the installed Steam executable. Package integrity, executable
versions and upload checksums were checked. Other storefronts/mods remain untested.
