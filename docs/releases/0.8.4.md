# Zero Hour Archipelago 0.8.4 — Steam and EA App

**Both Steam and EA App versions are tested and verified working.** Steam with
GenPatcher 2.14 fixes and GenTool 8.9 is also tested. Generals Online is not
compatible; GenLauncher and The First Decade are untested.

## Start here

Download **ZeroHour-Archipelago-0.8.4-Launcher.zip**, extract it, and follow its
**README.md**. Install the included **generals_zh.apworld** using **Install APWorld**
in Archipelago Launcher, restart the launcher, then open **Zero Hour Client**.
The APWorld includes the client and dependencies; no separate Python installation
or client download is needed.

[Read the full install-and-play guide](https://github.com/ItsMrNew/ZeroHour-Archipelago/blob/main/README.md).
Use **Zero Hour Options.html** to create your YAML, generate locally, and upload
the generated `AP_<seed>.zip` to [Archipelago Host Game](https://archipelago.gg/uploads).

## Features

- Story campaigns and Generals Challenges with configurable mission/set checks
  and victory goals.
- Mission-set unlocks, cross-faction builders, permanent abilities and optional
  Progressive Generals Powers.
- Helpful filler, weighted traps and optional DeathLink.
- In-game progress tracker, item notifications and live DeathLink settings,
  including access from the main menu.
- Light/dark client themes, saved connection fields and coloured item logs.
- Production Surge and Construction Boost: 2x training/construction speed for
  120 seconds of player control per item. Additional items extend duration.
- Power Outage disables radar even when campaign scripts force it on, as in
  China 1. The follow-up hook allocation fix is included.

## Versions and validation

Client **0.8.4**, world **0.21.0**, protocol **18**, tested with Archipelago **0.6.7**.
This integration targets Windows single-player campaigns and Generals Challenges.

Validation: **1,340 automated tests passed, 5 skipped**; YAML creator checks passed.
The packaged client has been launched and reused from an isolated copy of the real
Archipelago Launcher. In-game installation and connection have user confirmation.
Production/construction speed boosts still need in-game confirmation.

Dependency notices and licenses are included. No game installation is bundled.
