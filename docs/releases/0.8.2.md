# Zero Hour Archipelago 0.8.2 - Steam preview

This release contains only the Archipelago client, world, options creator,
Archipelago tests, build tools and documentation.

- Mission-lock warnings and return-to-menu confirmations appear red in both themes.
- Steam + GenPatcher v2.14 (Fixes Applied) and Steam + GenTool v8.9 installed through
  GenPatcher are user-tested as working.
- GenLauncher remains untested; GeneralsOnline requires a separate engine adapter
  and remains unsupported.

Extract the Steam ZIP into its own folder and launch ZeroHourClient.exe. Keep the
bundled licenses folder. Existing compatible rooms, seeds and progress remain
supported: world 0.20.0 and protocol 17 are unchanged.

Assets: Steam client ZIP, clean source ZIP, generals_zh.apworld, release notes
and SHA256SUMS.txt.
