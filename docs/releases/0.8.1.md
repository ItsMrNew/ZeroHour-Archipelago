# Zero Hour Archipelago 0.8.1 - Steam preview

- Mission-lock warnings and return-to-menu confirmations now appear red in the
  launcher's log, in both Light and Dark mode.
- Updated compatibility reports: Steam + GenPatcher v2.14 (Fixes Applied) and
  Steam + GenTool v8.9 installed through GenPatcher are user-tested as working.
- GenLauncher is untested. GeneralsOnlineZH.exe remains unsupported; the reported
  Easy Anti-Cheat installation has not been tested with this client.

Extract the Steam ZIP into its own folder and launch ZeroHourClient.exe. Existing
compatible rooms, seeds and progress remain supported; no new YAML is needed.
World 0.20.0 and protocol 17 are unchanged.

Assets include the Steam client ZIP, source ZIP, generals_zh.apworld, release notes
and SHA256SUMS.txt. Keep the bundled licenses folder with the client.
