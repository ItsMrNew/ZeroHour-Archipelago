# Zero Hour Archipelago 0.8.3 - Steam and EA App preview

Stock English Steam and EA App Zero Hour on Windows are supported for campaigns
and Generals Challenges. One Windows package works with both installations.
GeneralsOnline is not compatible.

The inspected EA App build passes all 327 native address checks, and its mapped
executable sections match the historical supported Steam baseline exactly.
Validation against the EA installation: 1,236 tests passed; one historical Steam
backup fixture was skipped. Initial gameplay tests were reported successful.
Windows prevented independent live-process inspection; full details are in the
bundled EA App validation report.

Launcher labels, compatibility guidance, setup instructions and issue templates
now reflect both supported storefronts. Native checks remain enabled for every
executable. No new seed is required: world 0.20.0 and protocol 17 are unchanged.

Download ZeroHour-Archipelago-0.8.3-Windows.zip and extract the complete folder.
Keep the included licenses. Start Zero Hour from Steam or the EA App, then open
ZeroHourClient.exe and connect normally.

Players launch ZeroHourClient.exe directly. Diagnostic shortcuts call their
console executable directly; no Start Client batch file is included.

Access-denied game-process messages appear red in the launcher log in both themes.
