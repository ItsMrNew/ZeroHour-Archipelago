# Launcher icon

`icon.png` is a small-size adaptation of `assets/zero_hour_archipelago.png`,
created with the built-in image generation tool. It is packaged only into the
packaged launcher APWorld. The original asset remains unchanged.

## Generation prompt

Edit this emblem into a compact launcher icon optimized to read clearly at only
48x48 pixels. Preserve its identity: metallic golden left wing transitioning to
blue at bottom, green right wing transitioning to purple, central white star and
eagle, dark red sword. Make the main winged emblem much fuller and taller to
occupy a near-square silhouette, shorten the thin sword handle above the wings
and lower blade below it so these thin extensions no longer waste the icon space.
Bold clean high-contrast edges, reduce fine noisy texture. Tightly frame with only
2% transparent margin on a square canvas. No background, no text, no added symbols,
preserve true alpha transparency. This is a small-size adaptation of the supplied
exact emblem, not a new logo concept.
